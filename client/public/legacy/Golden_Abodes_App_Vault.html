Each project has subfolders per app (V3, Planning, Cashflow, Marketing & Sales Command Centre, etc.). Open views PDFs in this browser; Download saves a copy to disk where you choose. Save to Cloud syncs PDFs to the same Google Apps Script file as Project Acquisition (GA_Planner_Data.json) so teammates can Load from Cloud in any browser.

Important: Websites cannot open Windows File Explorer. The copied path is only useful if you set a real folder root below (e.g. D:\Work\GoldenAbodes\DocVault) and create folders manually on your shared drive — then paste the path in Explorer’s address bar.
